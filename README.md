# Práctica V – Herramientas colaborativas

## 📌 Descripción del proyecto

Este proyecto corresponde a la **Práctica V: Herramientas colaborativas**, del módulo de **Entornos de Desarrollo**, perteneciente al ciclo formativo de Grado Superior de Desarrollo de Aplicaciones Multiplataforma (DAM).

El objetivo principal de esta práctica es poner en práctica los conocimientos sobre programación, control de versiones y trabajo colaborativo mediante el uso de herramientas como Git y GitHub.

El desarrollo se realizará en equipo, utilizando una metodología de organización de tareas que permita distribuir el trabajo, realizar un seguimiento de los avances y mantener un control de los cambios realizados en el proyecto.

## 🎯 Objetivos

- Desarrollar una solución en C# organizada en diferentes proyectos.
- Implementar funcionalidades mediante métodos independientes.
- Crear menús interactivos que permitan al usuario seleccionar las operaciones disponibles.
- Aplicar buenas prácticas de programación.
- Utilizar Git y GitHub para gestionar el código fuente.
- Trabajar de forma colaborativa mediante ramas, commits y Pull Requests.
- Organizar y distribuir las tareas entre los integrantes del equipo.

## 🛠️ Tecnologías y herramientas

- **C#:** lenguaje de programación utilizado para desarrollar las funcionalidades.
- **Visual Studio:** entorno de desarrollo.
- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para alojar el repositorio y gestionar el trabajo colaborativo.

## 📂 Estructura del proyecto

La solución está organizada en cuatro proyectos independientes, cada uno centrado en un apartado de programación:

### 1. Array

Contiene funcionalidades para trabajar con estructuras de datos de tipo array:

- Calcular el valor máximo.
- Calcular el valor mínimo.
- Calcular la mediana.
- Calcular la media.
- Ordenar un array de menor a mayor.
- Calcular la desviación típica.
- Binarizar un array en función de un número determinado.

### 2. Número

Incluye operaciones matemáticas y algoritmos relacionados con números:

- Comprobar si un número es primo.
- Calcular el factorial.
- Convertir segundos en horas, minutos y segundos.
- Obtener los primeros 15 números de la serie de Pell.
- Comprobar si un número es de Armstrong.
- Comprobar si todos los dígitos de un número son diferentes.

### 3. String

Incluye diferentes operaciones para trabajar con cadenas de caracteres:

- Comprobar si una cadena es un palíndromo.
- Convertir un nombre a mayúsculas y minúsculas.
- Contar las ocurrencias de una letra.
- Repetir dos cadenas un número determinado de veces.
- Duplicar cada carácter de una cadena.
- Eliminar de una cadena las apariciones de otra cadena.

### 4. Decimales

Contiene operaciones matemáticas relacionadas con números decimales:

- Redondear un número al alza.
- Eliminar la parte decimal de un número.
- Resolver una ecuación de segundo grado a partir de sus tres coeficientes.

## 🔄 Metodología de trabajo

Para desarrollar la práctica se utilizará GitHub como herramienta principal de colaboración y organización.

Se seguirán las siguientes prácticas:

- Distribución de las tareas entre los integrantes.
- Creación de ramas para desarrollar funcionalidades.
- Realización de commits con mensajes descriptivos.
- Uso de Pull Requests para revisar e integrar los cambios.
- Seguimiento del progreso mediante las herramientas de gestión de proyectos de GitHub.
- Revisión y comprobación del funcionamiento de las funcionalidades desarrolladas.

No se realizarán desarrollos directamente sobre la rama principal (`main` o `master`).

## ▶️ Ejecución del proyecto

1. Clonar el repositorio en el equipo local.
2. Abrir la solución con Visual Studio.
3. Seleccionar el proyecto que se desea ejecutar.
4. Iniciar el programa.
5. Utilizar el menú interactivo para seleccionar la funcionalidad deseada.
6. Introducir los datos solicitados por teclado y consultar el resultado.
